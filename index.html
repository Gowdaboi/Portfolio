Dues Desk — Claude-Native Collections Follow-Up Product

Zero-LLM-cost collections desk where the customer's own Claude drafts follow-ups over 7 idempotent MCP tools while Next.js + Supabase enforce state logic and mandatory human approval.

Proof: Live App + Public MCP Architecture
Live App ↗ Architecture & README ↗

01. Problem & User Pain

SMBs need consistent invoice follow-ups, but existing AI tools either charge steep SaaS markups, require handing over sensitive LLM API keys, or risk sending unreviewed, hallucinated reminders to customers.

02. System Architecture & Guardrails

Customer's Claude Desktop/Code ──[7 Idempotent MCP Tools]──▶ Next.js MCP Server
│
Human Approval Queue ◀──[State Gate: Paid=Skip, Promised=Pause]─┴─▶ Supabase (Postgres + RLS)

03. Product Decisions & Trade-offs

  • Zero-LLM-Cost Architecture: No LLM calls or AI keys live on the server; the customer's own Claude client generates drafts via MCP while the app acts as the deterministic state & guardrail engine.
  • State-Driven Guardrails: Marking an invoice 'Paid' automatically skips pending follow-ups; 'Promised-to-Pay' pauses reminders until the promised date.
  • Mandatory Human-in-the-Loop: Every outbound collection message requires explicit human sign-off before dispatch, paired with workspace Row-Level Security and per-workspace rate caps.
04. Verified Outcome

Specified, built, and deployed to production in 24 hours with 7 idempotent MCP tools and multi-tenant RLS isolation.

AI Decision Engine • 2,500+ Automated Tests Expand Architecture & Trade-offs Collapse ▸

AI Job Intelligence Agent — Human-in-the-Loop Copilot

Local-first Python & SQLite decision system separating deterministic hard eligibility filters from a 9-dimension AI scoring rubric and citation-verified application prep.

Proof: ~2,500 Tests • Deterministic + LLM Hybrid
GitHub & Architecture Docs ↗

01. Problem & User Pain

Job boards produce volume without signal, while generic AI auto-apply bots hallucinate resume claims, waste tokens on ineligible listings, and spam recruiters.

02. System Architecture & Guardrails

11 ATS Sources ──▶ Dedup ──▶ Deterministic Hard Filters (Rules Cannot Be Overridden)
│
You Apply ◀──[Citation Verifier]◀── Human Review ◀── 9-Dim AI Rubric + Bounded Learning (±5 cap)

03. Product Decisions & Trade-offs

  • Deterministic Rules Before AI: Hard constraints (experience math, salary floor, blocked titles) execute first—a high LLM score can never rescue an ineligible job.
  • Bounded Preference Learning: User feedback adjusts future rankings within strict mathematical guardrails (±2.5 pts per preference, ±5 pts total) and only after explicit user approval.
  • Citation-Grounded Generation: Every claim in generated briefs or answers must resolve to an indexed profile evidence ID; structural grep tests enforce zero auto-submission code.
04. Verified Outcome

Backed by ~2,500 unit, integration, and structural invariant tests; runs 100% locally with full deterministic fallback when no API key is configured.
